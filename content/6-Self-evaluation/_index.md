## Looking Back on 12 Weeks of Internship

After 12 weeks working on SmartDorm, here's an honest look at how I see my own progress — not just a scorecard, but real notes on the process:

| Criteria | Self-rating | Concrete example |
| :--- | :---: | :--- |
| **Backend technical skills** | Good | Built the entire API by hand with ASP.NET Core, from basic CRUD to complex business flows like auto-approval and contract generation. |
| **Cloud infrastructure mindset** | Good | Successfully moved from a traditional EC2 setup to a serverless architecture with Lambda, and understand the trade-off between cost and cold-start latency. |
| **Self-learning & research** | Good | When Lambda couldn't write to local disk, figured out the fix by switching to the S3 SDK without needing step-by-step mentor guidance. |
| **Frontend** | Fair | Only contributed basic support (a few demo pages, sample API calls); this is an area I'm still limited in and want to develop further after the program. |
| **Time management** | Good | Kept to the weekly plan set out since week 3, with no missed reporting deadlines. |
| **Communication & teamwork** | Fair | Communicated clearly with the teammate handling the frontend about API data formats, though explanations were sometimes longer than needed. |
| **Troubleshooting** | Good | Successfully debugged a tricky CORS issue between the Vercel domain and the Lambda endpoint, as well as a race condition when two approval requests hit at once. |
| **Actual project contribution** | Good | A complete SmartDorm Backend, running live on AWS with full API documentation, ready for extension or handoff. |

### What I'd like to improve
Given more time, I'd want to invest more in the frontend to better understand how a complete product operates end-to-end, rather than staying focused mostly on the Backend as I did this time.
